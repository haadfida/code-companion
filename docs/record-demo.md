# Recording the demo GIF

Output file: `docs/demo.gif` (referenced from the README).

1. Launch the extension (F5 Extension Development Host, or install the `.vsix`) and open a small sample web project.
2. Open the CodeCompanion sidebar from the Activity Bar.
3. In the chat view, type `Add dark-mode toggle` and press Enter.
4. Wait for the generated execution plan and keep it on screen for a few seconds so the steps are readable.
5. Apply the plan and show the resulting diff / edited files.
6. Keep the recording under ~30 seconds, about 1000px wide.

Suggested tools: macOS screen recording + `ffmpeg`, or LICEcap / ScreenToGif. Save as `docs/demo.gif` and commit.
